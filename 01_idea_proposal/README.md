# 01 Idea proposal

The first capstone assignment: a one-page proposal with five sections (project idea, relevance to the SDGs, two literature examples, data, and the choice between machine learning and deep learning).

| File | What it is |
|---|---|
| `Fatura_Dedektifi_Group14_Idea_Proposal_EN.pdf` | The proposal in English, one page. The `.docx` is the editable source. |
| `Fatura_Dedektifi_Grup14_Fikir_Onerisi_TR.pdf` | The same proposal in Turkish. |
| `slides/Fatura_Dedektifi_Group14_Slides_EN.pdf` | Eleven slides used in the presentation, English. |
| `slides/Fatura_Dedektifi_Group14_Slides_TR.pdf` | The same slides in Turkish. |
| `slides/narration_EN.md`, `slides/narration_TR.md` | The text spoken over the slides. |
| `slides/src/` | The script that builds both slide decks and prints the PDFs. |
| `proposal_src/` | The script that builds both proposal files. |
| `analysis/` | The scripts that produced the numbers and the charts in the proposal, with their results. |

The presentation was recorded as a narrated video. The video files are not kept in this repository.

Every number in the proposal that comes from the data can be reproduced with `analysis/first_look.py`, and the tariff costs with `analysis/tariff_cost.py`. See `analysis/README.md`.

After the idea presentation the instructor asked for the cost side to use Türkiye's day and night tariff and for a plan to adapt the UK data to Türkiye. The proposal, slides 9 and 10, and the tariff analysis were added in response.
